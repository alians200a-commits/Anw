# فتح وتحرير النموذج

1. استخرج جميع ملفات الحزمة إلى مجلد، ولا تفتح ملف ZIP نفسه داخل InDesign.
2. افتح Chemistry-Editorial.idml من File > Open في InDesign 2023.
3. أبقِ مجلد Links بجانبه. إذا ظهرت صورة مفقودة، استخدم لوحة Links وأعد الربط بملف cover-editorial.jpg.
4. يلزم خط Cairo بأوزانه Regular وMedium وSemiBold وBold وBlack؛ الخطوط ليست مضمّنة في الحزمة.
5. راجع اتصال العربية واتجاه الرموز (+3 وP وS وns²)، وعدم وجود نص زائد، ثم ترتيب الصفحتين والصورة.
6. احفظ نسخة INDD بعد نجاح الفتح. لا تُعدّل ملفات XML يدوياً.

النصوص والرموز والعناصر الهندسية مستقلة وقابلة للتحرير في IDML؛ الصورة فقط JPEG مركّب. الأنماط المسماة تضبط العناوين والمتن والأسئلة والتسميات، والألوان CMYK مسماة. طبقات منفصلة للخلفية والصورة والأشكال والنصوص والتسميات والترويسة/التذييل. ترقيم النموذج ثابت لصغر النطاق، وليس فهرس كتاب تلقائياً.

PDF معاينة للمراجعة، وليس ملفاً طباعياً نهائياً أو إثباتاً لمطابقة محرك InDesign. إذا ظهر اختلاف، تكفي لقطة للصفحة ورسالة الخطأ أو وصف الفرق لتشخيصه.
