# فحص نموذج الاتجاه الجديد

الحالة: **مسودة اعتماد من صفحتين، لا فصل نهائي ولا اعتماد لجميع بوابات المشروع**.

| الفحص | النتيجة المشاهدة |
|---|---|
| صورة افتتاح كبيرة R1/R10 | الصورة من المستخدم، تمتد عبر نحو 70% من الارتفاع؛ ليست توليداً جديداً |
| الاندماج R2/R25/R27 | نزف سفلي وجانبي وانتقال علوي ناعم، وشخصية تتفاعل مع المشهد؛ لا إطار أبيض حول الصورة |
| عائلات المكونات R3/R4/R24 | ست عائلات مبينة في design-decisions.md؛ التعليلان مختلفان عن قائمة التصنيف |
| أرقام ورسوم R5 | +3 بارز؛ خمسة عناصر في بنية واحدة؛ اتجاه نوعي بلا مقياس كمي مختلق |
| القراءة والألوان R6/R7/W1–W3 | متن 14.5/20 داكن على فاتح، السؤال أحمر، العناوين كحلية، لا متن فوق صورة |
| التصغير R8 | فُحصت صورة الصفحتين؛ بطل افتتاح واضح وكتلة تصنيف ومسار رأسي في المقابلة |
| المسافات R9/R18/R28 | هوامش النص 15 مم؛ آخر خط للخلاصة عند 275 مم وبداية التذييل 284 مم، فاصل 9 مم |
| الأصالة والتوقيع R11/R17/R22/R26 | تصميم جديد؛ توقيع ثلاث نقاط/مسار ثابت؛ لا شعار أو شخصية مأخوذة من صور المراجع |
| الثقل البصري R13 | الافتتاح مشهدي؛ حقل التصنيف 180×44 مم مع عنوانه ومسار تصنيفه هو المرتكز في الصفحة الكثيفة |
| أسلوب الصور R14/R16 | استُخدمت صورة واحدة من المستخدم لضمان عدم خلط أساليب؛ المعلمة موجودة بالافتتاح |
| الرسوم العلمية R15 | لا ذرة أو جهاز جديد في هذا النطاق؛ رموز التصنيف 24 نقطة |
| مرونة النص R18 | نجحت ملاءمة الـ44 إطاراً في محرك معاينة PDF، دون تقليص؛ تحقق InDesign معلق |
| الصفحة المشهدية R19 | لا بطاقات فوق الشخصية؛ العنوان والتمهيد خارج جسمها |
| النظام والإيقاع R20/R21 | افتتاح مشهدي يقابله شرح تحليلي؛ سلالم الخط موثقة |
| نقد المدير الفني R23 | موثق مع تحديد حدود العينة في design-decisions.md |
| المراجعة R29 | ثلاث نسخ مصوّرة؛ أصلحت المحاذاة والرموز وارتفاع IIIA والتذييل وأعيد التصدير |
| الطاقم الثانوي R30 | غير منفذ في العينة؛ لا ادعاء باستيفاء شرط مشاهد الفصل الكامل |
| المختبر R31 | لا تجربة مختبرية في هاتين الصفحتين؛ غير مختبر |
| قابلية التحرير R12 | ملف IDML به نصوص وأنماط وألوان وطبقات؛ الفتح الفعلي في InDesign غير متاح هنا |
| W4/W5 | شخصية واحدة من صورة المستخدم، لا إعادة توليد لملامحها |
