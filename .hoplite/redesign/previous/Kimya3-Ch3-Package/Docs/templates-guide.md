# دليل القوالب (إنديزاين 2023)
- الطبقات (من الأسفل): خلفيات ← صور ← قوالب وأشكال ← نصوص ومعادلات ← تسميات وأسهم ← رأس وتذييل.
- الصفحات الرئيسية: A (ترويسة + تذييل + رقم تلقائي)، B (تذييل فقط للافتتاح). الغلاف بلا صفحة رئيسية.
- أنماط الفقرة: متن، متن-صغير، متن-عريض، سؤال-شريط، تعليل-سؤال، درس-عنوان، عنوان-فرعي، معادلة/معادلة-يمين/يسار، تسمية-رسم...
- أنماط الحرف: إبراز، إبراز-أساسي، تعليل-حرف، وسم-مصدر (مهم/وزاري)، صيغة/صيغة-سفلي/صيغة-علوي، تسطير.
- الأسهم ورمز Δ مرسومة كأشكال (خط Cairo لا يحويها).
- إن طال نص بعد التعديل: اسحب الإطار والبطاقة التي تحته معاً (لهما الاسم نفسه في لوحة الطبقات).
