# من المحتوى إلى الشكل: لا تنضّد، حوّل

المصمم الخبير لا يضع الفقرة في صندوق؛ يسأل: **ما شكل هذه الفكرة؟** ثم يبني الشكل. أي إجابة أطول من ثلاثة أسطر أو قائمة أطول من ثلاثة بنود تُحوَّل إلى بنية بصرية. ظهر الفشل في `assets/failure-case/fourth-attempt-v9-skill.pdf`: كل الأسئلة بنفس «شريط + بطاقة نص» رغم تنوع محتواها.

## جدول التحويل
| نوع المحتوى | الشكل البصري |
| --- | --- |
| خطوات عملية أو مراحل | **مسار مرقّم بأسهم** (بطاقات أو محطات) بترتيب القراءة العربي، وصورة مصغرة لكل خطوة إن أفادت |
| مقارنة بين شيئين (حديد/ألمنيوم) | **مواجهة**: مشهد منقسم نصفين أو عمودان متقابلان، عنوان لكل جانب، ونقاط متوازية، ونتيجة في المنتصف |
| قائمة استعمالات أو أمثلة | **مشهد مجمَّع** بأرقام مرتبطة بتسميات، أو شبكة أيقونات/بطاقات صغيرة |
| تصنيف أو أنواع | **شجرة** أو بطاقات متفرعة بخطوط وصل |
| تعريف | بطاقة تعريف بكبسولة عنوان تعبر الحافة، وصورة صغيرة ترمز للمصطلح |
| معادلة تفاعل | **شريحة معادلة** بأيقونة، وشرح الأطراف تحتها (راسب، غاز، أيون) بخطوط وصل |
| أرقام ونسب | **إنفوغرافيك مقيس** (أعمدة، طبقات، مقياس) بقيم حقيقية وتسميات مباشرة |
| تدرج في خاصية | شريط تدرج لوني بسهم |
| جهاز أو خلية | قطع كبير مسمّى (≥ 40% من عرض الحقل) بخطوط وصل مرقمة تعود إلى الإجابة |
| سبب/تعليل | بطاقة تعليل مميزة + رسم يوضح السبب إن أمكن |
| ملاحظة أو تنبيه | لسان حاشية |
| سؤال غير محلول | شريط تمرين بمساحة كتابة + المعلم |
| جدول مطابقة | جدول بصري بخطوط وصل أو ألوان للمطابقة |

## قواعد
1. **ثلاثة أنماط إجابة مختلفة على الأقل في كل صفحتين** (قائمة، مواجهة، مسار، شريحة معادلة، مشهد مرقّم، شجرة...). لا تكرر «شريط سؤال + بطاقة نص» أكثر من مرتين متتاليتين دون تغيير في بنية الإجابة.
2. **الإجابة الطويلة:** إن زادت عن ثلاثة أسطر فاستخرج منها كلمات مفتاحية وفكرة بصرية، وأبقِ النص كاملاً (حفظ الأصل) لكن ضمن بنية: عناوين فرعية ملوّنة، فقرات قصيرة، أيقونات، وصور مصغرة.
3. **الصورة بحسب الفكرة:** الصورة المرافقة لإجابة تبيّن الفكرة (مقطع الخلية، المقارنة، التأثير)، وتكون بالأسلوب الموحد (انظر image-generation.md)، لا لقطة مخزون عامة.
4. **أشكال الصور:** لا مستطيل بزوايا حادة وخلفية بيضاء. استعمل قوساً أو دائرة أو شكلاً بزاوية L أو قصاً نظيفاً يعبر الحافة أو نزفاً كاملاً مع بطاقات طافية.
5. **الصفحة كلها فكرة:** كل صفحة تروي فكرة واحدة بصرياً (عنوانها يُقرأ من الصورة قبل النص).
6. **علامات الأهمية** (مهم، وزاري) كشارات منفصلة بجانب السؤال لا تُلصق بحرف السؤال.
