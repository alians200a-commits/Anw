# أطلس التصميم: أنماط مستخرجة من مراجع كيمياء إضافية

المصدر: ست صفحات كيمياء مرجعية (كهروكيمياء وكيمياء تناسقية) في `assets/reference-chem-1.jpg … 6.jpg`، وقالب شريط السؤال المؤطَّر في `assets/reference-template-question-bar.jpg`. هذه **أنماط تصميم مجرّدة** تُعاد صياغتها بهوية أصلية. لا تنسخ شخصياتها (المحقق ببدلة ومعطف، العالم الشارب...)، ولا ألوانها بالضبط، ولا أسماء المدرسين أو الحسابات أو شعار الدار. أنشئ شخصياتك وقوالبك من هذه الأفكار.

## 1. أسلوب الرسم
الأسلوب المرجعي ليس صوراً فوتوغرافية وليس كرتوناً مسطحاً: **رسم سينمائي منمّق (painterly)**: ملامح معبّرة بمبالغة خفيفة، حركة وإيماءة واضحة، ألوان غنية، إضاءة ناعمة عالية الإشراق، وبيئة بخلفية مضببة قليلاً. اعتمده كتفسير لـ«كرتوني سينمائي». ثبّته في كل الكتاب. صور واقعية فوتوغرافية (كما في صفحة الكيمياء التناسقية) تكسر الوحدة ويجب تفاديها.

## 2. أنماط المشاهد (الأقوى تأثيراً)
1. **الصفحة هي المشهد.** خلفية الصفحة مشهد كامل بنزف (نافذة بضوء، أفق، مختبر) عالي الإشراق وهادئ التفاصيل، وبطاقات المحتوى **تطفو فوقه** بشفافية جزئية (≈ 85–92%) وظل ناعم، فتقرأ الصفحة كمجلة لا كورقة. حافظ على تباين النص ≥ 4.5:1 داخل البطاقات.
2. **المشهد هو الشكل العلمي.** التجربة تُرسم كحدث بشخصيات تتفاعل معها (يشير، يفحص بعدسة)، وتُعلَّق عليها عناصر العلم كشرائح صغيرة قابلة للتحرير (اتجاه الإلكترونات، الأقطاب، الجسر الملحي). الرسم يخدم الفهم قبل الجمال.
3. **استعارة بصرية للفكرة المجردة** (شخصية تسحب عربة عليها بطارية = نقل الطاقة)، على أن تُعلَّم كتشبيه ولا تُقدَّم كتمثيل علمي.
4. **الأدوات الحاملة للمعنى:** قوارير ليكندات بأسمائها على رف، علبة زجاجية يتوهج داخلها بناء جزيئي، كتاب يحمل عنوان الموضوع. (النص على الأدوات يُنضَّد كطبقة قابلة للتحرير فوق الصورة لا داخلها.)
5. **عبور الطي:** عنصر كبير (شخصية، جهاز) يمتد عبر الصفحتين المتقابلتين ويربطهما. **حافظ على الوجوه والتفاصيل العلمية بعيداً عن منطقة التجليد (≥ 15 مم من الطي)** حتى لا تُقصّ.
6. **النافذة المستديرة/القوسية:** بطل مقصوص داخل دائرة أو قوس لوني، يتجاوز بجزء منه الإطار، ويمسك لافتة بعنوان الدرس (العنوان يُنضَّد فوق الدعامة كنص مستقل).
7. **طاقم متكرر (إلزامي في مشاهد الدروس):** شخصية عالِم تاريخي (صاحب القانون أو الاكتشاف يظهر في صفحة اكتشافه) + طالب/طالبة + فنّي مختبر عند الحاجة، بالإضافة للمعلم عند الغلاف والواجب. الطاقم يعطي قصة مستمرة. صمّمهم أصلياً بورقة شخصية لكل واحد. (ظهور المعلم الإلزامي: الغلاف وصفحات الواجب، انظر image-generation.md.)
8. **نظرة الشخصية تقود القارئ** نحو النص أو المحتوى، وإشارتها تدل على الوحدة المقصودة.
9. **مناظر مرتبطة بالفصل:** نافذة بضوء دافئ للتعريفات، مختبر أزرق للتجارب، رف ملوّن للتصنيفات. تتغير البيئة بين الصفحات والأسلوب ثابت.

## 3. مكتبة القوالب (تشريح قابل للتنفيذ)
كل قالب نمط كائن مسمى، بلون الفصل، وتفصيل توقيع واحد على الأقل:

| القالب | التشريح |
| --- | --- |
| **شريط السؤال المؤطَّر بقوس** (مرجع: `assets/reference-template-question-bar.jpg`) | وسم «سؤال» بنقطة صغيرة فوق الشريط، وخط رفيع يمتد منه ثم ينحني نزولاً نحو طرفي الشريط فيكوّن **قوساً مفتوحاً** يؤطر الشريط من أعلاه؛ الشريط ممتلئ بلون الفصل بزوايا مدورة والنص أبيض ثقيل. متغيرات لونية (برتقالي، أخضر…) لكل فصل. **يجب أن يكبر ارتفاع الشريط ويلتف السؤال الطويل على أسطر**؛ لا قص للنص ولا أسطر مبتورة كما في المثال الثاني بالصورة (نص مقطوع). |
| **شريط السؤال (س)** | رأس شريط ملتصق بجسم بطاقة بنفس العرض؛ شارة دائرية عند طرف البداية فيها رقم أو أيقونة صغيرة؛ كبسولتان وخط صغير فوق الشريط كتوقيع؛ الجسم بطاقة فاتحة بلون الفصل؛ بنود مرقمة 01 02 03 بأرقام ملوّنة والكلمات المفتاحية بلون المساعد. |
| **بطاقة التعريف** | بطاقة دافئة (كريمية) بعنوان على شكل كبسولة **تعبر حافتها العلوية** وفيها أيقونة (بإشارة دلالية مثل البرق للكهرباء)؛ وسم صغير «عرف» في الجهة المقابلة؛ حافة مفتوحة: خط رفيع على ضلعين فقط (يمين وأسفل). |
| **بطاقة التعليل** | حقل وردي/أحمر فاتح، وسم «علل» في زاويته، والجواب بشارة دائرية «ج»؛ شكل مختلف بنيوياً عن السؤال. |
| **شريط التمرين/الواجب** | بشكل شريط السؤال لكن **جسمه مساحة فارغة للكتابة** (إطار ناعم)، لتمارين الطالب غير المحلولة. هنا يظهر المعلم يقدّم التمرين. |
| **بطاقتا قانون جنباً إلى جنب** | إطار بخط ملوّن بلا تعبئة، وكبسولة العنوان «القانون الأول/الثاني» **على منتصف الحافة العليا** (تقطع الخط). |
| **شريط القسم** | شريط عريض ملوّن بأقراص زخرفية عند الطرفين (كأنه شريط لاصق)، يفتح القسم. |
| **عنوان الدرس** | شريط داكن بإطار خطي مزاح فوقه (تكرار مزاح للإطار)، وعنوان أبيض ثقيل. |
| **عنوان فرعي مرقّم** | كبسولة ملوّنة بدائرة رقم عند اليمين، تحتها نقاط بنفس لون الفصل. |
| **شريحة معادلة** | كبسولة صغيرة بأيقونة (دورق) تحمل المعادلة، أو جدول معادلات: كل سطر معادلة يسارية + وسم عربي ملوّن (نصف تفاعل أكسدة…) وخط فاصل قبل المحصلة. |
| **ملاحظة** | وسم كبسولة سماوية «ملاحظة» + بنود مرقمة، أو أيقونة سهم/مصباح بجانب الفقرة. |
| **شجرة التقسيم** | عنوان في الأعلى بخطوط وصل منحنية إلى بطاقتين (أو ثلاث) برقم كبير رفيع 01 02 وكبسولة عنوان. |
| **جدول** | رأس لون صلب، عمود أول مرقّم بشريط ملوّن، صفوف متناوبة الفاتح، بلا شبكة ثقيلة. |
| **رسم مصغّر مؤطّر** | قطع علمي صغير مسمّى داخل إطار مدور بحد، يجلس داخل بطاقة النص بجانب الفقرة (مع بقاء الرسم الكبير في المشهد). |
| **التذييل** | كبسولة باسم المادة/المدرس + شارة دائرية برقم الصفحة، بوزن بصري خفيف. |

## 4. تفاصيل التوقيع (اختر ثلاثاً أو أربعاً للكتاب وكررها بدقة)
- كبسولتان + خط فوق شرائط الأسئلة.
- أيقونة دلالية في عنوان التعريف (برق للكهرباء، قطرة للمحاليل، ذرة للعناصر...) بنظام واحد.
- شارات دائرية بأرقام للأسئلة والفقرات.
- حافة مفتوحة على ضلعين للبطاقات الدافئة.
- أقراص زخرفية عند أطراف شرائط الأقسام.
- وسوم صغيرة (عرف، علل، ملاحظة) بشكل ثابت.
أصل **هذه التوقيعات** في الأصالة: ابتكر أنت تفاصيل خاصة بالكتاب بدل نسخ حرفية.

## 5. الألوان والإيقاع
- المراجع تستعمل لوناً أساسياً قوياً (أزرق/أحمر ترابي/برتقالي) مع بطاقات كريمية وفاتحة؛ البطاقات الدافئة للتعريفات، والباردة (بلون الفصل) للأسئلة، والوردية للتعليل. اتبع هذا الفصل الوظيفي بلون الفصل الخاص بك.
- بالتناوب: صفحة بمشهد كبير تطفو عليه البطاقات، ثم صفحة بتركيب أنظم (بطاقات وجداول وشجرة) مع شخصية صغيرة أو بدونها.

## 6. مخاطر رُصدت في المراجع (تجنّبها)
- خلط واقعي مع رسوم منمّقة بالصفحة نفسها.
- وجوه أو تفاصيل علمية قريبة من الطي.
- بطاقات نصية متراصة بلا تنفس فوق مشهد مزدحم.
- مساحة كتابة فارغة بلا حدود واضحة أو بلا تمييز.
- تكرار الشخصية نفسها بالوضعية نفسها؛ نوّع الإيماءة والحجم.


## 7. أنماط إضافية من صفحتي فيزياء (Canva): `assets/reference-canva-physics-1.jpg` و`-2.jpg`
تُستخرج **المكونات فقط**؛ الصفحتان نفسهما نصيتان كثيفتان بلا بطل ولا مشهد، أي دون مستوى بوابة الكتاب. لا تتبع تخطيطهما الكلي.

| المكوّن | التشريح |
| --- | --- |
| **شريط سؤال بشارة «؟»** | شريط ممتلئ مدور (مرجاني أو بترولي) بنص أبيض، وشارة دائرية فيها علامة استفهام عند الطرف تتجاوز حافة الشريط قليلاً. للأسئلة التفكيرية. |
| **لوحة تفكير** | لوحة بترولية داكنة بإطار خطي مزدوج حول الشريط الممتلئ، وشارة «؟» عند الزاوية، لسؤال تحدٍّ أو سؤال تطبيقي طويل. |
| **بطاقة جواب بيضاء مدورة** | بطاقة فاتحة بحدّ رفيع مدور، **كلمات مفتاحية ملوّنة** (مرجاني) داخل النص، وخط حدّ ينتهي بنقطة صغيرة في زاوية البطاقة. |
| **وسم على الحافة (أدوات التجربة / الاستنتاج)** | كبسولة ملوّنة تجلس على الحافة العلوية لصندوق بإطار (بنفسجي أو وردي) وتقطع خط الحد؛ الصندوق فيه قائمة. |
| **قائمة أدوات بسهم** | بنود قصيرة بعلامة سهم/مثلث صغير في بدايتها (◁ في الاتجاه العربي) بدل النقاط، تناسب أدوات التجربة. |
| **شريط عنوان مقصوص** | شريط بترولي عريض يمتد من حافة الصفحة بنهاية مقصوصة، بوسم قصير («اكتشاف فاراداي») لتقديم تجربة أو قسم. |
| **صورة مدمجة بتعليق مرقّم** | صورة صغيرة داخل بطاقة بجانب النص، تحتها تعليق «الشكل (66)» بحجم صغير، وربط بالنص بالرقم. |
| **معادلة رمزية مضمّنة** | معادلة (مثل ΔΦ/Δt) داخل الفقرة بحجم المتن بمحاذاة يسارية. |
| **خلفية الصفحة** | تدرج أزرق فاتح هادئ مع لوحات بيضاء؛ تقرأ نظيفة. |

ملاحظات نقد: صغر الصورة (كلمة «الشكل» أصغر من القراءة)، تباعد أسطر ضيق، لوحة نص طويلة بلا بنية. حوّل هذه إلى بنى بصرية (content-to-visual.md) وكبّر الصورة العلمية حسب R15.
