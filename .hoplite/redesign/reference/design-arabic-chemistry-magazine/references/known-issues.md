# أخطاء معروفة (سجل حي)

يُحدَّث بعد كل مراجعة من المستخدم (لقطة شاشة + وصف). لكل بند: العرض، السبب، الإصلاح، اختبار المنع.

## من التجربة السابقة (انظر regression-case.md)
| العرض | السبب | الاختبار المانع |
| --- | --- | --- |
| خلفيات تغطي الصور والنصوص | ترتيب Layer معكوس | فحص ترتيب الطبقات (الخلفية أولاً) |
| تعبئة أشرطة النسب غير ظاهرة | ترتيب الرسم | التعبئة فوق المسار، وطولها من القيمة |
| رأس جدول مقصوص | ارتفاع صف أصغر من النص | قياس النص قبل تحديد الارتفاع |
| ترقيم الصفحات يختلف | بداية القسم | فحص الترقيم في المصدر والمعاينة |
| معاينة PDF سليمة والمصدر مختلف | PDF من تخطيط موازٍ | توليد الاثنين من وصف واحد |

## من مراجعات المستخدم لهذا المشروع
| العرض | السبب | الاختبار المانع |
| --- | --- | --- |
| صفحات تبدو ورقة تمارين بلا مشهد ولا شخصية | تعليمات تسمح بالتخلي عن البطل في الصفحات الكثيفة | البوابة البصرية: بطل ≥ 30% لكل صفحتين، وافتتاح فصل في الاختبار |
| كل الوحدات بنفس الصندوق | غياب تشريح مميز لكل وحدة | جدول التشريح في visual-gate.md |
| ألوان متقاربة | لون واحد وتدرجاته | لونان + ثلاث درجات وظيفية |
| صور واقعية بجانب شخصية منمّقة | لا لوحة اختبار أسلوب، وتغطية «الجمادات» غير صريحة | R14 + لوحة اختبار الأسلوب قبل الصفحات |
| كل الأسئلة بنفس الشريط والبطاقة | غياب قاعدة التحويل | R24 + content-to-visual.md |
| جهاز التوقيع على الغلاف فقط | غياب شرط تكراره | R26 |
| صور مستطيلة بخلفية بيضاء وقصاصة المعلمة داخل مستطيل | غياب قواعد شكل الصورة وتكامل الشخصية | R25 + R27 |
| جدول يلامس التذييل وفراغ أسفل الصفحة | لا فحص بصري للتصدير | R28 + R29 |
| نموذج آخر تجاهل شروط الصور والتخطيط (شخصية واقعية، جدول فوق الشخصية، صفحة مكدّسة بلا بطل) | مهارة طويلة تُنفَّذ دفعة واحدة بلا مراحل | عقد التشغيل + مراحل باعتماد المستخدم (launch-prompt.md) |
