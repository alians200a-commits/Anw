# مطالبة التشغيل (الصقها أنت مع المادة)

النماذج تتفاوت في الالتزام بالتعليمات الطويلة. هذه المطالبة تفرض مراحل قصيرة باعتماد المستخدم، وتُلصق مع أول رسالة (مع ملف المهارة والمادة).

```
استخدم مهارة design-arabic-chemistry-magazine. اقرأ SKILL.md كاملاً، ثم افتح المراجع المذكورة فيه قبل التنفيذ: visual-gate.md، content-to-visual.md، design-system.md، spread-library.md، creative-direction.md، design-atlas.md، image-generation.md.

قبل أي عمل اكتب «عقد التشغيل»: 12 سطراً بكلماتك تلخص القواعد غير القابلة للكسر (أسلوب منمّق موحد بلا صور واقعية، بطل بكل صفحة، تحويل المحتوى لبنى بصرية، المعلم بالغلاف والواجب، طاقم ثانوي ومختبر للتجارب، جهاز التوقيع بكل صفحة، لا نص فوق شخصية، هوامش ومسافات، نص حرفي مع قائمة تنبيهات، مراجعة مرئية).

نفّذ المراحل بالترتيب وتوقف بعد كل مرحلة وانتظر اعتمادي:
المرحلة 0 (الهوية): لوحة اختبار الأسلوب، أوراق الشخصيات (المعلم، طالب، عالِم)، مختبر الكتاب، جهاز التوقيع، Chapter Identity Kit للفصل.
المرحلة 1 (المخطط): لكل صفحتين: التخطيط من spread-library.md، البطل وفكرته، أنماط الإجابة، التوقيعات، مناطق النص. نصاً وبرسم تخطيطي بسيط.
المرحلة 2 (البناء): صفحات الاختبار (افتتاح + تجربة بمختبر وشخصية ثانوية + واجب بالمعلم). صدِّرها لصور وراجعها بصرياً ونفّذ تمريرتي تصحيح، ثم سلّم visual-audit.md بأدلة، وقائمة التنبيهات بأخطاء المصدر.
المرحلة 3: بقية الفصل.

ممنوع: صور واقعية، جدول أو بطاقة فوق وجه أو جسد شخصية، حقول فارغة بلا وظيفة، صفحة بلا بطل، تغيير نص المصدر.
```
