## Integration lock

- Do not hotlink IconScout preview media.
- Import IconScout assets only after an authorized download through the user's IconScout account/license.
- Prefer local project assets after download.
- Never loop forever. Play once on entry/press/open, then stop.
- Do not animate a static Phosphor/Lucide icon and call it the final animated asset.
- Keep Header / Footer / Logo unchanged.
- Do not change medical copy while performing icon work.
