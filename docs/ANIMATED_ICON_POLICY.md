# Daleeli animated icon source lock

Approved sources only:

1. Primary: IconScout — Medical Animation Pack (60 Lottie animations)
   https://iconscout.com/lottie-animation-pack/medical-animation-pack_197672
   Author: Bora Ezer

2. Secondary: Flaticon — Free Medical Animated Icons
   https://www.flaticon.com/free-animated-icons/medical

Rules:
- Do not substitute unrelated animated icons from either site.
- Do not use generic Home/Book/Test/Bookmark animations as replacements for the approved medical assets.
- Use animation for medical section meaning (medicine, monitoring, oxygen/breathing, emergency, equipment, records/guides, etc.).
- No infinite animation loops in the app.
- Play motion on entry/press/open only and keep it short.
- Prefer local licensed Lottie/GIF assets over runtime hotlinks.
- Keep the existing static icon as a fallback.
